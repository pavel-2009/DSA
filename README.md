# 📘 Курс: Алгоритмы и Структуры Данных
## 60-дневный интенсив для подготовки к IT-собеседованиям

**Язык:** Python (или Java/C++ по выбору)  
**Формат:** 1 час теории + 2 часа практики ежедневно  
**Цель:** 300+ задач, уверенное прохождение технических интервью

---

## 📋 Правила работы

- Каждый модуль = 3 дня
- После каждого блока — мини-проект или контест
- Ведение конспекта и трекинг задач обязательны
- Используйте LeetCode, NeetCode, Codeforces для практики
